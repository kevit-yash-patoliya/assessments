# React Challenges

## Run locally

```bash
bun install
bun run dev
```

## Challenges

- 1. **Counter** — update a local counter.
- 2. **Navigation** — navigate home, about pages using `react-router-dom`.
- 3. **Redux Counter** — manage a counter with Redux.
- 4. **Fetch Posts** — load posts titles from an API.
- 5. **Axios Interceptors** — send headers on every request.
- 6. **Todo List** — add and display the tasks.
- 7. **Simple Form** — Simple form using react-hook-form .
- 8. **Toggle Paragraph** — show or hide text.
- 9. **Reset Form** — Reset form after submit.
